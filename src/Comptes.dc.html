Le compte principal, en tête de liste, porte les mouvements par défaut : son remplacement passe par la promotion d'un compte secondaire.

Rattacher un compte bancaire externe à ce compte titres. C'est par lui que passent les mouvements d'espèces dans les deux sens : les versements qui alimentent le compte titres avant un achat, et les retraits qui rapatrient la liquidité disponible une fois les titres vendus. Sans compte rattaché, aucun mouvement de trésorerie n'est possible — le compte titres peut détenir des positions, mais rien n'y entre ni n'en sort. Le rattachement se contrôle sur la clé de l'IBAN, qui doit être conforme pour être enregistré.
