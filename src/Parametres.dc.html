ISO 10383 MIC Codification des places de négociation — structure du code et portée dans l'application

La norme ISO 10383 attribue à chaque marché un identifiant de quatre caractères, le MIC (Market Identifier Code). Ce code est la clé de rattachement retenue par l'application : il détermine le pays de source pour la fiscalité, la devise de règlement et le calendrier de jours ouvrés servant au calcul du délai de dénouement.
